# Traits

Traits can be edited freely. The number assigned to each trait is its relative probability of being assigned to a villager.

Traits are used to:
- Improve relationships between villagers
- Unlock special features
- Affect job performance

Traits are assigned when a villager is created and will not change afterwards. Existing villagers will keep their assigned traits even if you edit this file.

## Special Traits

The following traits have unique effects. Removing them or setting their weight to 0 will disable these features for newly created villagers.

MURDERER:
- Gives a villager a chance to kill other villagers.
- Witnesses will mark them as wanted.

COWARD:
- Villagers cannot become guards.
- They will flee from danger.

HARD_WORKER:
- Improves performance in any job.

LEARNER:
- Increases job skill gain.

## Job Performance Traits
These improve specific job performance and can be edited in the profession jsons

GARDENER, FARMER:
- Improves Farmer performance.

BRAVE:
- Improves Guard performance.

LOVES_ANIMALS:
- Improves Rancher performance.
- Stablehand
- Sheepherd

COOK:
- Improves Chef performance.

MINER:
- Improves Miner performance.

HISTORIAN, BOOKWORM:
- Improves Librarian performance.

STORYTELLER, TEACHER:
- Improves Teacher performance.

EXPLORER, ADVENTUROUS:
- Improves Trader performance.

MAGIC_LOVER:
- Improves Alchemist performance.
